# Заметки Миши

## Фичи бота

- Дает идеи для видео
- Делает анализ канала клиента, анализ его конкурентов
- Из идеи для видео делает что-то дальше, сценарий генерирует
- Описание, название, теги для видео генерирует
- Картинки для превью делает

## Логика бота

- Приветственное сообщение, рассказ фич
- Видос как работает бот, потом оплата с пользователя
- Анализ канала пользователя по ссылке:
  1. Фундамент канала, видео в одной нише
  2. Концепт...
  3. Шапка и описание
  4. И т.д. тут уточнить методологию
- Анализ конкурентов
- Дожим человека если он не купил
- Кто твоя целевая аудитория

## Меню бота

- Анализатор идей
- Написание сценариев
- Превью генерация
- Описание, название, теги
- Задать вопрос: диалог с ИИ на свободную тему
- Моя подписка / токены, продление

## Задачи

- Просчитать токеномику / подписки
- Разные модели для разных задач текста
- Свои модели для картинок
- Чтобы ИИ отвечала на основе нашей базы знаний и промптов
